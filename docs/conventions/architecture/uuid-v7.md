# UUID v7

## Convention

Use UUID version 7 (time-ordered UUIDs) for all entity identifiers generated by the server. UUID v7 values are time-sortable, which improves B-tree index performance in PostgreSQL compared to UUID v4.

Use the `uuid_extensions` library's `uuid7()` function for generation. This library produces RFC 9562-compliant UUID v7 values with sub-millisecond timestamp precision.

Apply `uuid7()` in two contexts:

- **Domain entities** (dataclasses): use `field(default_factory=uuid7)`
- **SQLAlchemy ORM models**: use `default=lambda: uuid7()` on the column definition

Do NOT use `uuid.uuid4()` for server-generated IDs. UUID v4 is acceptable only for client-generated identifiers (e.g., `distinct_id` sent by the CLI).

## Benefits

- **Better DB index performance** — UUID v7 values are time-ordered, reducing B-tree index fragmentation and page splits compared to UUID v4.
- **No coordination needed** — unlike auto-increment integers, UUID v7 can be generated independently by any server without collisions.
- **Standard library familiarity** — `uuid7()` returns a standard `UUID` object, compatible with all Python `uuid` module functions.

## Examples

### Good: Dataclass entity with UUID v7 default

```python
from dataclasses import dataclass, field
from uuid import UUID

from uuid_extensions import uuid7


@dataclass
class UsageEvent:
    event_id: UUID = field(default_factory=uuid7)
    ipy_version: str = ""
    operating_system: str = ""
```

### Good: SQLAlchemy ORM model with UUID v7 default

```python
import uuid

from sqlalchemy.dialects.postgresql import UUID
from sqlalchemy.orm import Mapped, mapped_column
from uuid_extensions import uuid7


class UsageEventModel(Base):
    __tablename__ = "usage_events"

    id: Mapped[uuid.UUID] = mapped_column(
        UUID(as_uuid=True),
        primary_key=True,
        default=lambda: uuid7(),
    )
```

### Bad: Using UUID v4 for server-generated IDs

```python
import uuid

@dataclass
class UsageEvent:
    # B-tree performance will degrade as the table grows
    event_id: UUID = field(default_factory=uuid.uuid4)
```

### Bad: Mutating default in dataclass

```python
@dataclass
class UsageEvent:
    # This creates one UUID at class definition time, shared across all instances!
    event_id: UUID = uuid7()
```
